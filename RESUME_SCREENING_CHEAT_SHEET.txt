┌──────────────────────────────────────────────────────────────────────────────┐
│ PARAMETERS EXPLAINED                                                         │
└──────────────────────────────────────────────────────────────────────────────┘

  top_n:
    - Number of top resumes to return
    - Range: 1-20
    - Freshers: 15-20
    - Senior: 5-8
  
  must_have_requirements: (Enhanced only)
    - Comma-separated critical requirements
    - Example: "5+ years Python,AWS certification,Team leadership"
    - Candidates not meeting these get score capped at 50
  
  nice_to_have: (Enhanced only)
    - Comma-separated preferred requirements
    - Example: "Docker,Kubernetes,Microservices"
    - Not meeting these doesn't penalize score
  
  min_embedding_score: (Enhanced only)
    - Minimum similarity threshold (0-1)
    - Default: 0.5
    - Strict: 0.6
    - Lenient: 0.4
  
  embedding_weight / llm_weight: (Enhanced only)
    - How to balance embedding vs LLM scores
    - Must sum to 1.0
    - Default: 0.3 / 0.7 (balanced)
    - Trust LLM more: 0.2 / 0.8
    - Faster: 0.4 / 0.6

┌──────────────────────────────────────────────────────────────────────────────┐
│ RESPONSE FIELDS                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

  Basic Response:
    - rank: Position in ranking (1, 2, 3...)
    - filename: Resume filename
    - similarity_score: Embedding similarity (0-1)
    - match_score: LLM match score (0-100)
    - recommendation: STRONG_FIT | GOOD_FIT | MODERATE_FIT | WEAK_FIT
    - summary: Overall assessment
    - strengths: List of positive points
    - weaknesses: List of gaps/concerns
    - skills_match: Matched vs missing skills
    - experience_match: Experience assessment
    - education_match: Education assessment
  
  Enhanced Response (Additional):
    - embedding_similarity: Embedding score (0-1)
    - llm_match_score: LLM score (0-100)
    - final_weighted_score: Combined weighted score (0-100)
    - meets_critical_requirements: true/false
    - critical_requirements_status: Status of each requirement
    - red_flags: List of concerns

┌──────────────────────────────────────────────────────────────────────────────┐
│ TROUBLESHOOTING                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

  Error: "No resume files uploaded"
    → Use key "resume_files" (plural) for each file
  
  Error: "Maximum 100 resumes allowed"
    → Split into multiple batches
  
  Error: "embedding_weight + llm_weight must equal 1.0"
    → Adjust weights to sum to 1.0 (e.g., 0.3 + 0.7)
  
  Error: "Unauthorized"
    → Check JWT token in Authorization header
  
  Low match scores for all candidates
    → Refine JD, lower min_embedding_score, or check requirements
  
  Processing is slow
    → Reduce batch size or top_n value
