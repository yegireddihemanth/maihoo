Create these in Postman Environment:

base_url          = https://your-api-domain.com
auth_token        = (auto-saved from login)
organizationId    = (auto-saved from login)
candidateId       = (auto-saved from create candidate)
verificationId    = (auto-saved from initiate verification)

╔══════════════════════════════════════════════════════════════════════════════╗
║                         AUTO-SAVE SCRIPTS                                    ║
╚══════════════════════════════════════════════════════════════════════════════╝

Add to "Tests" tab in each request:

Login:
  pm.environment.set("auth_token", pm.response.json().token);
  pm.environment.set("organizationId", pm.response.json().organizationId);

Create Candidate:
  pm.environment.set("candidateId", pm.response.json().candidateId);

Initiate Verification:
  pm.environment.set("verificationId", pm.response.json().verificationId);

║                         COMMON ISSUES                                        ║
╚══════════════════════════════════════════════════════════════════════════════╝

❌ "No session cookie"
   → Add: Authorization: Bearer {{auth_token}}

❌ "Candidate not found"
   → Check candidateId is correct

❌ "Verification not found"
   → Check verificationId is correct

❌ "Missing required field"
   → Ensure candidate has panNumber, aadhaarNumber, etc.

❌ "Check already completed"
   → Can't update COMPLETED checks
